# PHM Ford Vibration - Motor Vibration Anomaly Detection

## Overview
This project develops an AI model for predictive maintenance using the Ford open dataset. It applies classification algorithms to automotive system time-series data to identify defective products.

## Objective
- Analyze time-series vibration sensor data to detect anomalies
- Learn periodic patterns in sensor measurements and relationships between sensors
- Classify and predict motor system failures for proactive maintenance

## Dataset
- **Source**: Ford Motor Company open dataset
- **Type**: Automotive system time-series data
- **Application**: Predictive maintenance in manufacturing

## Algorithms
- Logistic Regression
- XGBoost
- Convolutional Neural Network (CNN)
- Recurrent Neural Network (RNN)

## Key Features
- Periodic characteristic analysis of sensor measurements
- Multi-sensor relationship learning
- Time-series classification and prediction
- Applicable to manufacturing defect detection
